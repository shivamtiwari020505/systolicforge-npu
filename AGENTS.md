# Project instructions

## Active scope

- Treat `docs/PROJECT_ROADMAP.md` as the active project plan.
- The current goal is to complete SystolicForge as an academic project and an
  interview-ready engineering portfolio.
- Prioritize reproducible verification, FPGA implementation evidence, a board
  demonstration, and clear technical communication.
- Do not use ignored commercial drafts to set project priorities. Commercial
  productization, licensing, and production qualification are outside the
  active completion scope unless the user explicitly changes that scope.
- Prefer finishing and documenting the existing end-to-end design before adding
  major features.
- Follow the numbered implementation sequence in the roadmap. Steps 1–4,
  including randomized differential verification and the UART-based
  host-programmable FPGA demo, are complete. The next milestone is step 5:
  archived real-FPGA implementation and board evidence.
- Update the active roadmap when a milestone is genuinely completed.

## Claims and evidence

- Distinguish simulated, synthesized, placed-and-routed, and board-measured
  results.
- Do not report timing closure, routed utilization, power, bitstream success, or
  hardware validation without the corresponding archived evidence.
